# 도화엘리시아 앱

이 폴더 전체가 GitHub Pages로 배포되는 앱입니다.

- `index.html` — 앱 (Classical 디자인)
- `support.js`, `_ds/` — 실행에 필요한 파일 (수정하지 마세요)
- `sw.js`, `manifest.webmanifest`, `icons/` — 앱 설치(PWA)용
- `uploads/` — 공지(`note_*.json`, `img/`)와 공지 목록(`notes-index.json`)

## 앱으로 설치 (PWA)
- 휴대폰에서 배포 주소를 열면 화면 전체를 쓰는 앱 화면으로 바뀝니다 (PC에서는 폰 모형으로 보입니다).
- Android 크롬: 메뉴 ⋮ → **앱 설치** (또는 "홈 화면에 추가")
- iPhone 사파리: 공유 버튼 → **홈 화면에 추가**
- 설치 후에는 주소창 없이 앱처럼 열리고, 뒤로가기 버튼으로 이전 화면으로 돌아갑니다.
- `.nojekyll` 파일을 꼭 함께 올리세요 (GitHub Pages에서 `_ds` 폴더가 빠지는 것을 막습니다).
- 앱 파일을 수정해 다시 배포했는데 반영이 안 되면 `sw.js`의 `dohwa-v8`을 `dohwa-v9`처럼 올려주세요.

## 로그인 · 고지서 · 입금 내역
- 로그인, 고지서, 입금 내역, 비밀번호 변경은 구글시트에 연결된 Apps Script 웹앱이 처리합니다 (`index.html`의 `PAY_URL`).
- 매월 고지서는 구글시트 `고지서` 시트에 엑셀 `관리비산정내역` 표를 붙여 넣으면 바로 앱에 표시됩니다. 이 저장소에 올릴 파일은 없습니다.
- 고지서는 로그인한 세대에게 그 세대 것만 전달됩니다. 한 번 로그인한 폰에서는 인터넷이 안 될 때도 마지막으로 받은 고지서를 볼 수 있습니다.

## 공지
- 관리인이 앱에서 작성하면 이 저장소의 `uploads/`에 저장되어 1~2분 뒤 모든 폰에 표시됩니다 (관리인 화면의 비밀번호 탭에서 GitHub 연결 필요).

## 주의
- 파일을 더블클릭해 여는 방식(file://)으로는 동작하지 않습니다. 반드시 웹 서버에 올려서 여세요.
- 이 저장소는 공개입니다. `uploads/`에 올린 파일은 주소를 아는 사람이면 누구나 볼 수 있으므로 고지서나 비밀번호 같은 자료는 올리지 마세요.
