# 도화엘리시아 앱 배포

이 폴더 전체를 정적 호스팅(GitHub Pages, Netlify, Vercel 등)에 올리면 됩니다.

- `index.html` — 앱 (Classical 디자인)
- `support.js`, `_ds/` — 실행에 필요한 파일 (수정하지 마세요)
- `uploads/bills-data-yyyy-mm.json` — 월별 고지서 데이터

## 앱으로 설치 (PWA)
- 휴대폰에서 배포 주소를 열면 화면 전체를 쓰는 앱 화면으로 바뀝니다 (PC에서는 폰 모형 + 설명 패널).
- Android 크롬: 메뉴 ⋮ → **앱 설치** (또는 "홈 화면에 추가")
- iPhone 사파리: 공유 버튼 → **홈 화면에 추가**
- 설치 후에는 주소창 없이 앱처럼 열리고, 뒤로가기 버튼으로 이전 화면으로 돌아갑니다. 한 번 열었던 화면은 오프라인에서도 열립니다.
- `.nojekyll` 파일을 꼭 함께 올리세요 (GitHub Pages에서 `_ds` 폴더가 빠지는 것을 막습니다).
- 앱 파일을 수정해 다시 배포했는데 반영이 안 되면 `sw.js`의 `dohwa-v1`을 `dohwa-v2`처럼 올려주세요.

## 매월 고지서 올리기
`uploads/` 폴더에 `bills-data-2026-10.json` 처럼 해당 월 파일을 추가하면 가장 최근 달이 자동으로 이번 달 고지서가 됩니다. 최근 6개월 파일은 지난 내역에 실제 데이터로 표시됩니다.

## 주의
- 파일을 더블클릭해 여는 방식(file://)으로는 JSON을 읽지 못합니다. 반드시 웹 서버에 올려서 여세요.
- 현재 로그인 비밀번호, 공지 작성, 읽음 확인은 프로토타입 수준으로 브라우저 안에서만 동작하며 새로고침하면 초기화됩니다. 실제 운영에는 서버(로그인·저장)가 필요합니다.
- 고지서 JSON이 공개 폴더에 있으면 주소를 아는 사람은 누구나 열람할 수 있습니다.
